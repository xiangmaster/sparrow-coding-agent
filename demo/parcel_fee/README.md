# 校园快递配送费示例

这是 Sparrow 的固定演示项目。它模拟一个已经上线、但在金额和重量边界上出现
回归缺陷的校园快递配送费计算器。

`calculate_delivery_fee(subtotal_yuan, weight_kg, is_member=False)` 应遵守：

- 普通用户订单金额达到 99 元免配送费；会员达到 69 元免配送费。
- 未达到免配送门槛时，首 1 千克收 8 元。
- 超过 1 千克的部分按每开始 1 千克加收 2 元，例如 1.01 千克收 10 元，
  2.2 千克收 12 元。
- 订单金额不能为负数，重量必须大于 0；非法输入应抛出 `ValueError`。

运行测试：

```bash
python3 -m unittest -v
```
